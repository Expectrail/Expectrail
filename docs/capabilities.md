# What Expectrail can do, and how far each part is proven

<!-- Rendered from docs/capabilities.json by `python3 -m expectrail.capabilities render`. Edit the JSON, not this file. -->

One row for every mode a reader of the README or the site could believe exists. Each row says how
far the mode is proven (its status), what kind of evidence its best recorded run produced (its
grade), and links the test, the record or the CI run that shows it. The same data is in
[`capabilities.json`](capabilities.json); `tests/test_capabilities.py` fails when a row marked
measured has no run link, when a link points at a file that is not there, and when the README or
the site names a command, a switch, a workflow, a doc page or a watched name that no row lists.
The checked pages are README.md, docs/index.html, docs/concepts.html and docs/run-it.md.

Every run link carries the run's conclusion as GitHub's API gave it when the row was written. The
test reads that recorded value, not GitHub. A measured or integrated row may cite only runs
recorded as success. Any other row that cites a run that ended another way says so beside the
link, with the reason it is evidence all the same.

A count beside a run link ("8 of 8") is checked only where the row ties it to the notices the
run published, which is where the bench jobs put their public counts. Such evidence ends with
"Counted from the run's notices", and `python3 -m expectrail.capabilities recheck` counts those
notices again from GitHub. Of the 23 counts quoted beside a run link, 13 are tied to notices; any other is as the row's writer wrote it, and no check has compared it with its run.
Across all rows citing one run, its entries must together account for every notice their title
rules select. A notice selected by no entry is a problem. Entries may overlap; an entry without
`where` includes every notice its title rules select.

Last changed 2026-11-16. 41 rows: 12 implemented, 17 integrated, 7 measured, 5 experimental. By grade: 11 fixture, 30 diagnostic, 0 isolated, 0 protected.

## Status

| Status | Means |
| --- | --- |
| `implemented` | The code is in the repository and its tests pass in CI. It has run only on recorded or synthetic inputs, or has no recorded end-to-end run. |
| `integrated` | Wired into the path a user takes (a command, a workflow or the site) and exercised there by a CI job or a recorded run. No published result rests on it. |
| `measured` | A recorded CI run produced a result that the README, the site or a bench record publishes. The row links the run. |
| `experimental` | Built and possibly run, but parked, a trial, or advisory and unmeasured. Do not rely on it; it may change or go. |

## Evidence grade

| Grade | Means |
| --- | --- |
| `fixture` | Saved or synthetic data, for demos and tests. Never clears a release. |
| `diagnostic` | A real run: the engine or the browser ran, or a live model answered, on a developer's machine or a CI runner, with isolation as declared. Does not clear a release. |
| `isolated` | The game ran sandboxed with no network, the checks came from the base commit, and a separate trusted job judged and signed. No row has this grade yet: the replay sandbox and the two-job Action alone do not establish the full boundary; signed judging and deployment evidence are still needed. |
| `protected` | Isolated, plus capture the game cannot forge. Reserved until the capture spike (#246) shows a way; the check refuses this grade. |

## Changing the ledger

Edit [`capabilities.json`](capabilities.json), run `python3 -m expectrail.capabilities render`, and
commit both files. Move a row to `measured` only with the link of the CI run that produced the
number. The benches under [`bench/`](../bench/README.md) are records of runs, not modes: a row
links to them, they have no rows of their own. The check on what the README and the site name is
mechanical: it sees commands, `EXPECTRAIL_` switches, workflow files, doc pages, the Meta models
table and the names under `nameWatch`. A mode described only in prose, under a name nobody
added to that list, gets past it.
