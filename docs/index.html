Know what this does not establish.

  • Fixed routes and approved windows cover only what they exercise. Check scope · Route scope.
  • The game writes its own frames and trace; capture is not protected from a deliberately malicious game. Capture limits.
  • No ledger row has isolated or protected grade. A diagnostic accept is not release clearance. Sandbox limits · Signing limits.
