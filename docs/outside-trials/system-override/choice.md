# Third outside-project choice — fixed before integration inspection

Chosen on November 15, 2026 (America/Chicago), before reading game code, scenes,
input settings, or attempting Expectrail onboarding.

**System Override**, by **aleshg / Aleš Gajdacz**, is the fixed choice:
https://github.com/aleshg/SystemOverride

Pin: `f95712a9e88480251e3ba38880d7144bf3f7b33a`.

Why: its public README describes a playable top-down space shooter with enemy
spaceships, with a published playable build. It is a small independent author's
project, not another godotengine demo and not a starter template. Movement and
shooting offer game-specific behaviour to check without assuming platformer
floors. The repository search reported 39,576 KiB; this is a bounded small game,
not a large asset collection. No candidate was benchmarked or onboarded before
this choice. The search results included templates; only this game's README and
licence were opened for eligibility, not its implementation.

The README names Godot **4.1 (mono)**. That is recorded here before the trial;
it has not been tested with Expectrail's engine, and could be a toolchain blocker.
We will not swap the game if that or any other integration is difficult.
