# Generated release dossier (#268)

## What changed

Built on main `a5b7d95057ca1de0d1041f61eecd53ff16ff90ee`, branch `chatgpt/268-dossier`. Added an offline standard-library generator and its generated release page, linked once from the index. The generator reads an explicit allowlist of public records; it does not crawl links, run experiments, read private material or promote ledger grades. Each visible numerical value links to its recorded run, pinned repository source or captured public API comment. Input content digests identify the snapshot. Missing or contradictory evidence fails without replacing the previous output.

The dossier contains the capability snapshot, published blind aggregates, public reproduction counts and defect families, the committed release-control summary, outside-project verdicts, recorded Run it verdicts, recorded durations/costs and tracked limitations. False accepts, false rejects and needs-review are separate. Reproduction and held test controls are not relabelled as verification error rates. Small samples are explicitly scoped. Comparable repeated timings can produce nearest-rank percentiles; current singleton timings leave p50/p95 not measured. Historical/list-price estimates are not billed per-verification costs.

Two public #263 comments are captured with their original URLs. They record both the no-vision outside trial and its later unsuccessful vision attempt. The latter is not called the first successfully verified outside project. Blind test 4, that successful outside verification, and the first-user test remain not run yet; the first-user part is needs-sean for Sean or Timothy to arrange.
