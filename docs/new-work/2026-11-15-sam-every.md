# Set how often SAM is asked about a frame, with one frame plan across the three pixel jobs (#286)

## What changed
The SAM observer asked about every 10th frame of a probe and its last, and nothing could change that
from the command line. At `MAX_FRAMES` 30, a probe whose check names the enemy or the bullet could
reserve 30 x 3 x 9 x $0.0025 = $2.025, over the $2 per-change cap, so it was `not-run` unless the route
was cut with `--sam-first`.

- `--sam-every N` on `run` and `pixel-ask` (1 to 60, 10 by default) sets the observer's `every`. The
  observer refuses anything above 60 (`MAX_EVERY`: one frame a second at 60 fps), as it already refused
  anything below 1. The default is unchanged, so every existing command line asks as before.
- jit.yml has a `sam_every` input (default `10`). The plan job checks it is a whole number from 1 to 60
  and hands it to `replay-final` (capture), `pixel-ask` and `pixel-judge`, which each check it again and
  pass `--sam-every` once. No other job takes it. No secret, environment or permission changed.
- One frame plan across the jobs, failing closed. `RecordedSamClient` now reads the frames each recorded
  run was asked about (`framesProbed`, else the frames its rows cover) and `plan_of` gives them; the
  observer refuses, before it sends or judges anything, a recording whose plan is not its own. Before,
  a judging job with a sparser plan than the asking job would judge fewer frames than were paid for and
  say nothing; a denser one stopped part way. Both are now refused with "ask and judge with the same
  `--sam-every` and `--sam-first`". A capture kept at one plan and asked at a denser one was already
  refused (a planned frame is missing) and still is.
- What a sparser plan costs in evidence: `never-crosses` and `inside-region` fail on any failing frame,
  so sampling can only miss failures. A check the bug breaks only between sampled frames is then not
  kept (it does not fail 3 of 3 on the bug build). Stated in `docs/jit.md`.

Test changes to existing files (no assertion loosened):
- `tests/test_jit_cli_observer.py`: the `args_of` helper builds the namespace the parser builds, so it
  now carries `sam_every` (default 10).
- `tests/test_jit_pixel_workflow.py`: three exact command lines now end in `--sam-every 10`; and
  `assertNotIn("--sam-", run)` on the capture step, whose purpose is that the capture job is given no
  way to ask SAM, is now three assertions, one each for `--sam-answers`, `--sam-live` and `--sam-run`.
  `--sam-every` is the frame plan, not a way to ask.
