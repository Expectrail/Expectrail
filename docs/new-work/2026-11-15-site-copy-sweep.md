# The site's wording reads as a person wrote it

## What changed

Sean asked for a sweep of the website for wording typical of AI writing, dashes included. Claims, numbers and links
are unchanged; only how sentences are put changed.

- `docs/positioning.html` (23 edits): the heaviest page. It repeated one hedge, "this is X, not Y", about ten times
  ("not a claim that…", "not an exclusive feature claim", "not a claim of superiority"), and used inflated terms
  ("macro bottleneck", "cross-product invariant", "mathematically gameable", "changes the economics"). Headings and
  sentences now say the same things plainly, for example "Writing code is cheap now. Checking it isn't." and "Why one
  source of evidence is easy to fool". The model roles, numbers, runs and limits are all kept.
- `docs/guides.html` (9 edits), `docs/quickstart.html` (4), `docs/concepts.html` (3): the stiffest hedges rewritten
  in everyday words ("So far it has only been tested offline; nobody has run it end to end on a hosted repository
  yet."). Natural ones are kept ("This installs the checkout, not a package from PyPI.").
- Dashes: every em and en dash in visible text on these pages is gone. Page titles use "Page | Expectrail" in place of
  "Page — Expectrail", and "frames 0–119" reads "frames 0 to 119". The demo page had none; its "×" and arrows are a
  speed control, a close icon and a value change in code.

Left out on purpose:

- `docs/index.html` is in open PR #518 (direction B); sweeping it here would conflict. It gets the same sweep after
  #518 merges.
- `docs/release/index.html` is generated by `tools/dossier.py` as a release evidence record, where the careful
  hedging is deliberate.
- The Run it, verify and review pages had no em dashes or repeated hedges.

## What was run

On `claude/site-copy-sweep`, from main `282f3c8`:

- A script counted em and en dashes and the "X, not Y" hedge on each page before and after. Before: positioning 11
  hedges and 1 em dash in text, guides 9, quickstart 6, concepts 1 and an en dash. After: 0 dashes on every swept page;
  2 hedges left, both natural ("…an option, not a recommendation", "…the checkout, not a package from PyPI").
- `python3 -m tools.front_door`: 0 problems, no network requests. `python3 -m expectrail.capabilities check`: exit 0.
- `python3 -m agents.check_pages docs --offline`: 15 pages, 0 problems.
- The five-page front-door browser check at 1440x900 and 390x844: 10 of 10 passed.
- `python3 -m unittest discover -s tests -t .`: `Ran 3920 tests`, `OK (skipped=40)`.

## Not done

- No AI-detection tool was run. Such detectors are unreliable and none is available here; the sweep removes the
  patterns readers recognise, which is the part that can be checked.
- The home page (after #518) and the README are not swept in this change.
