<h2 id="limits">Known limitations and owners</h2><ul>
<li>The game originates its frames and trace; capture the game cannot forge is not established. <a href="https://github.com/Expectrail/Expectrail/issues/246">#246</a></li>
<li>The replay sandbox shares the host kernel and does not bound total job disk usage. <a href="https://github.com/Expectrail/Expectrail/issues/253">#253</a></li>
<li>Open release controls remain open; the dossier does not substitute unit-test counts for integration coverage. <a href="https://github.com/Expectrail/Expectrail/issues/258">#258</a></li>
<li>Observation-timeline controls still need their recorded release-suite evidence. <a href="https://github.com/Expectrail/Expectrail/issues/257">#257</a></li>
<li>Signed release receipts remain separate work. <a href="https://github.com/Expectrail/Expectrail/issues/255">#255</a></li>
<li>Reproduction misses and the unavailable baseline score artifact limit the public bench analysis. <a href="https://github.com/Expectrail/Expectrail/issues/285">#285</a></li>
<li>The outside trial is a small seeded demo cohort, not a successfully verified customer project. <a href="https://github.com/Expectrail/Expectrail/issues/263">#263</a></li>
<li>The hidden-player reject in the outside vision trial measured the background at the player’s position. <a href="https://github.com/Expectrail/Expectrail/issues/330">#330</a></li>
<li>Hand-dispatched Run it samples do not establish a deployed visitor service. <a href="https://github.com/Expectrail/Expectrail/issues/265">#265</a></li>
<li>Comparable repeated runtime samples, billed per-profile costs and environment image digests are incomplete. <a href="https://github.com/Expectrail/Expectrail/issues/268">#268</a></li>
