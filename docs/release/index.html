Known limitations and owners

  • The game originates its frames and trace; capture the game cannot forge is not established. #246
  • The replay sandbox shares the host kernel and does not bound total job disk usage. #253
  • Open release controls remain open; the dossier does not substitute unit-test counts for integration coverage. #258
  • Observation-timeline controls still need their recorded release-suite evidence. #257
  • Signed release receipts remain separate work. #255
  • Reproduction misses and the unavailable baseline score artifact limit the public bench analysis. #285
  • The outside trial is a small seeded demo cohort, not a successfully verified customer project. #263
  • The attempted outside vision run could not locate the player; usable visual coverage remains a blocker. #330
  • Hand-dispatched Run it samples do not establish a deployed visitor service. #265
  • Comparable repeated runtime samples, billed per-profile costs and environment image digests are incomplete. #268
