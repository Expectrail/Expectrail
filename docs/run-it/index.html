Run it

Pick a change to Expectrail's sample game. Expectrail plays the game with that change, watches it, and says whether the change holds. Nothing to install.

The game run and the checks are live on every visit. The vision model's answers are recorded once for each sample, so a visit spends nothing: a frame that is not in the recording gets no answer, and the run then says it needs review rather than guess. A sample whose answers are not recorded yet cannot be accepted, and its result says so.
